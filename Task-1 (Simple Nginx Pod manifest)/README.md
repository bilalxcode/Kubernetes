# Simple Nginx Pod Manifest

## Task Overview:
This task involves creating a Kubernetes Pod manifest to deploy an Nginx container. The manifest defines a pod named `nginx-pod`, running the latest version of the official Nginx image and exposing port 80.

## What to Do:
- Create a Pod manifest for deploying Nginx.
- Use the Nginx image (`nginx:latest`).
- Expose port 80 to access the Nginx server.
