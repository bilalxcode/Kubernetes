    <h1>Simple Nginx Pod Manifest</h1>

    <h2>Task Overview:</h2>
    <p>This task involves creating a Kubernetes Pod manifest to deploy an Nginx container. The manifest defines a pod named <code>nginx-pod</code>, running the latest version of the official Nginx image and exposing port 80.</p>

    <h2>What to Do:</h2>
    <ul>
        <li>Create a Pod manifest for deploying Nginx.</li>
        <li>Use the Nginx image (<code>nginx:latest</code>).</li>
        <li>Expose port 80 to access the Nginx server.</li>
    </ul>
